# 🦁 Zoo Arcadia - Application Web

## 📌 Description
Zoo Arcadia est une application web permettant aux visiteurs de consulter les animaux, services et horaires du zoo.

## 🛠 Technologies
- **Frontend :** HTML, CSS, JS (ou Angular)
- **Backend :** PHP (PDO) ou Node.js (Express)
- **Base de données :** MySQL + MongoDB
